# **App Name**: AuraEstates

## Core Features:

- Immersive Navigation Bar: A fixed top navigation bar featuring a sleek logo, essential links (Buy, Rent, Sold, New Homes, Commercial, News), and user authentication actions, transitioning from transparent to a Glassmorphic blur with scroll.
- Dynamic Parallax Hero Search: A stunning, high-resolution background image with a smooth parallax effect, overlaid by a centrally positioned, rounded Glassmorphism search widget for various property categories (Buy, Rent, Sold, etc.).
- Property Search Functionality: Enable users to search for properties by suburb, postcode, or school within the interactive Glassmorphism search widget.
- Enhanced Property Listings Display: Display property information in a horizontal carousel of cards, featuring high-quality images and a Glassmorphism overlay for key details (price, address, beds/baths/cars).
- AI-Powered Property Summary Tool: Utilize generative AI to provide concise, bullet-point summaries of complex property descriptions, highlighting key features and selling points for quick user digestion.
- User Authentication: Allow users to sign in or join the platform, enabling personalized features and saved properties.
- Saved Properties Management: Enable users to save their favorite properties, which are then accessible for later viewing and management via a general database.

## Style Guidelines:

- Primary interactive color: A vibrant, deep emerald green (#0BA376), chosen to convey prestige and trust, making it ideal for buttons, active states, and highlights against darker backgrounds.
- Background tone: A rich, very dark forest green (#1C2623), deeply desaturated to subtly infuse brand identity while supporting the moody, premium aesthetic and providing a strong contrast for glassmorphic elements and text.
- Accent color: A soft, radiant mint green (#97DEAB), offering a harmonious contrast to the primary green and dark background, bringing a touch of lightness and modernity to key interface elements without overpowering.
- Body and headline font: 'Inter' (sans-serif), selected for its clean, geometric, and highly readable design, ensuring a modern and objective aesthetic suitable for both concise headings and detailed property information.
- Sleek and crisp SVG icons are essential for a modern and refined look. Icons for beds, baths, and cars should be minimalistic to maintain aesthetic consistency within glassmorphic overlays.
- Heavy use of Glassmorphism for containers and interactive elements, creating frosted, semi-transparent layers with distinct backdrop blur effects to simulate depth and elegance. Parallax scrolling backgrounds provide immersive visual storytelling as users navigate.
- Subtle yet engaging animations include scroll-triggered fades and slides for content sections, a gentle shimmer effect across glassmorphic panels, and smooth transition effects for all interactive elements to enhance the premium feel.
